阅读静态示例不写用户数据库。只有明确点击创建体验副本或游戏安装/开始，才调用现有工作区或产品导入服务；原示例和用户原作不被覆盖。短篇全文按导入正文保存为可编辑草稿，不伪造 AI 生产与发布记录。

世界衍生游戏使用已冻结的产品发行包，各自拥有运行存档和媒资，不回写世界。社区原型的现有许可与来源声明继续保留。示例内容按需加载，展示使用实际作品封面与内容，不展示旧编辑器截图。

实现入口为 `src/components/examples/ExampleLibrary.tsx`；来源仍为本目录及 `public/games`、`public/prototypes`、`public/demo-assets`。新建社区跑团副本使用跑团 Work 类型，历史导入的发行包也能在跑团库中找到；游玩复用原桌面与检查点逻辑并嵌入新版外壳。不增加表或 schema，不新增模型调用。回归覆盖在 `tests/e2e/example-library.spec.ts`，包括空库展示、全文和下载、移动端漫画、导入副本隔离、备份恢复、损坏发行包及真实游玩入口。
