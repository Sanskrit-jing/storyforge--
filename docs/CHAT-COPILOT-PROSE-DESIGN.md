# AGENT-1 Phase 27.1-d · ChatCopilot 正文生成闭环

> 状态：已完成并通过完整交付验证（2026-07-26）。本文只覆盖空白章正文生成与已有正文显式
> 续写，不代表自动改写、后台整理本章 Agent 或多 Agent 团队已完成。

## 1. 用户故事与范围

- **稳定 ID**：`AGENT-1-27.1-d-prose`。
- 作者在唯一主 Agent 中明确“写第 N 章正文”或“续写第 N 章正文”，无需选择正文分 Agent。
- 目标只从当前世界规范章序中的既有章纲解析：明确标题优先、明确章序其次；未明确时，
  生成选择首个空白章，续写选择最后一个有正文的章节。
- 普通生成不会覆盖非空正文；“重写/改写/覆盖”请求明确阻断并引导到正文编辑器的对照
  改写能力。

## 2. 读、生成与确认

```text
用户要求
  → 主 Agent prose 任务
  → 现有章节生成 CONTEXT_SOURCES → assembleContext()
  → chapter.content / chapter.continue 正式提示与模型路由
  → 可见纯文本候选（作者可编辑 / 拒绝）
  → 目标章 + 章纲 + 正文 fingerprint 并发 gate
  → adopt(chapters) 原子写入
  → 旧检索块清除并重建，派生摘要标记 stale
```

- 读取复用章节编辑器使用的章纲、细纲、世界观、角色、规则、Canon、认知、物品、事实、
  状态、故事线、伏笔、历史、地点、远距前文召回和作者风格等登记源；不扫描第二套 store。
- 候选生成与拒绝均零内容表写入；确认对作者眼前文本重新执行长度 gate，不再次调用模型。
- 空白章确认时新增正式 `chapters` 记录；续写只把候选追加到当前正文，不替换原稿。

## 3. 数据安全边界

- 候选 80–200,000 字符；空壳和超限在写前阻断。
- 快照冻结 `outlineNodeId/updatedAt`、章节 ID/updatedAt、正文长度与双 hash fingerprint、
  是否已有正文和规范 order。确认时在同一 Dexie 事务重读；任一变化都拒绝旧候选。
- 新增/更新只经 `FIELD_REGISTRY + ADOPTION_SCHEMAS + adopt(chapters)`；没有新表、迁移或
  导出格式。
- 正文落库事务同步删除该章旧 `retrievalChunks` 并把相关 `narrativeSummaryNodes` 标记
  stale；事务后从确认正文重建检索块，避免旧正文继续作为 RAG 证据。
- 多世界项目必须先选世界，只能选择该世界规范章序中的章纲。

## 4. 当前非范围

- 不覆盖、重写、润色或批量改已有手稿；这些仍走正文编辑器的对照预览/撤销入口。
- 不在同一轮“新建章纲后立刻写正文”；新章纲必须先由作者确认进入正式数据，再发起正文。
- 不自动抽取状态、事实或章节记忆；正文写入后只处理确定性的检索缓存和摘要失效。
- 不后台运行、不自动采纳、不并行生成多章。
