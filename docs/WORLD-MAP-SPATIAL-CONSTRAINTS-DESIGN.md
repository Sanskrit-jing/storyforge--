# WORLD-1 / ENH-WORLDMAP-2 空间约束地图设计

> 状态：已完成（2026-07-25）  
> 前置：地图段一“读全用户已填内容”已完成  
> 目标：忠实还原规模、距离与相对位置，不重写现有 Voronoi 地形引擎

## 一、现状与裁决

现有地图引擎能生成地形、河流、国家、城市、道路和比例尺，但 AI 只输出宏观参数与
名称列表。名称虽然正确，坐标仍由随机种子决定，因此“A 在 B 东侧”“两城相距百里”
和“大城/村落”不会真正体现在地图上。

本阶段采用一层可回放的空间约束模型：

```text
用户世界观 / Codex / 重要地点
  → AI 抽取定性实体与关系（无数据库 ID、带原文证据）
  → 本地校验与单位换算
  → 确定性约束布局求解
  → Voronoi 生成时把命名城市/首都放到最近可用陆地
  → 国家从受约束首都扩张，河流按目标区域匹配
  → 规模影响领土权重、图标与字号，距离锚定比例尺
```

不让 AI 直接输出最终像素坐标，也不把用户设定改写回世界观。地图配置仍保存在当前世界
节点的 `mapConfigJSON`，相同种子和约束可重复生成。

## 二、空间契约

### 2.1 实体

每个实体使用名称而非数据库 ID：

- `kind`：国家、聚落、要塞、山脉、河流、区域、地标；
- `scaleTier`：超级大陆、帝国、王国、省域、大都会、大城、重镇、城镇、村落、要塞、
  普通地标；
- 国家可声明 `capitalName`，使国家方位约束落实到首都播种点；
- `source` 为 `explicit` 或 `inferred`；explicit 必须带能在输入中逐字找到的证据。

### 2.2 关系

- 方位：北、东北、东、东南、南、西南、西、西北；
- 距离档：接壤、近、中、远、极远；
- 显式距离保留原值和单位：公里、里、日程、月程；
- 本地统一换算：公里原值；里按 0.5 km；日程按 30 km；月程按 900 km。后两者明确
  标为旅行估算，不冒充用户给出的绝对公里数；
- 关系两端都必须存在于本次实体闭集；无效引用直接拒绝。

## 三、比例尺优先级

1. 用户明确给出世界/疆域横向尺寸：`mapWidthKm / canvasWidth`；
2. 用户明确给出至少一组距离：按关系距离档的目标画布长度取中位数锚定；
3. 都没有：使用默认估算值，并在 UI 标记“估算”，不伪装成用户设定。

手动修改比例尺继续允许，并写回当前世界节点配置。

## 四、确定性布局

- 名称哈希提供稳定初始位置；
- 方位关系使用八向单位向量；
- 距离档或显式距离提供目标长度；
- 迭代求解同时最小化方位误差、距离误差和实体重叠；
- 所有坐标限制在安全边距内；
- 矛盾关系不会丢弃，求解结果记录残差诊断，UI 提示存在冲突而不是静默假装满足。

## 五、引擎接入

- 受约束的命名城市在目标坐标附近选择适宜度最高且未占用的陆地 cell；
- 国家实体通过 `capitalName` 对齐首都，规模档调整扩张权重；
- 河流名按求解目标点与现有河流中点的距离匹配，不强行扭曲水往低处流的物理路径；
- 山脉、区域和地标作为空间标签叠加；不制造第二套可编辑地点数据库；
- 城镇规模影响图标半径、标签字号与人口权重；
- 没有空间约束的旧配置完全走原生成路径，保持兼容。

## 六、边界

- 本阶段保证命名实体的相对布局与比例关系，不承诺重画精确国界或让河流逐点经过用户
  描述的每个地名；
- 绝对公里数只有在用户提供尺寸/距离锚时才是设定值，其余必须显示为估算；
- AI 推断只补缺口，不能覆盖 explicit 关系；
- 多世界严格使用当前世界的输入和当前世界节点配置。

## 七、完成判据

1. 方位、距离、单位换算、比例尺与矛盾诊断有纯函数测试；
2. 同种子同约束坐标稳定，东/西/南/北和远近断言成立；
3. 命名城池落在陆地，国家从受约束首都扩张，规模影响渲染；
4. explicit 关系没有逐字证据时降级，不作为用户事实；
5. 旧地图配置正常加载，自动/手动比例尺持久化；
6. 全量 Vitest、真实浏览器、TypeScript、构建、架构与文档门禁通过。

## 八、交付结果

- `spatialEntities / spatialRelations` 随当前世界节点 `mapConfigJSON` 保存，无新增数据库表；
- AI 只抽名称、规模、八向方位和距离，explicit 必须命中用户消息逐字证据，非法枚举、
  闭集外端点和伪造证据由本地 parser 拒绝或降级；
- 确定性求解器公开比例尺来源与冲突残差；手动比例尺会写回当前世界，自动比例尺由同一
  配置稳定重算；
- 首都/城镇选择约束点附近的适宜陆地，国家规模影响扩张，聚落规模影响人口、图标和
  字号，河流只匹配物理河道，山脉/区域/地标使用覆盖标签；
- 保留原 Voronoi 地形、道路、省份、导出和无空间约束旧配置路径。

验证证据：`R-worldmap-spatial-layout.test.ts` 覆盖单位换算、四级比例尺优先级、稳定布局、
方位/远近、矛盾诊断、证据闭集和真实引擎陆地落点；Chromium 从真实世界观字段经兼容
API 生成地图，验证用户尺寸来源、命名实体渲染、手动比例尺写回与刷新恢复。
