# RAG-1 · 可见资料与检索库

> 状态：核心交付完成（2026-07-26）
>
> 目标：让作者看见项目里哪些输入可能进入创作、精确选择记录/字段、控制权重与预算，并能
> 检查每次节点运行真正召回了什么；不复制第二份 Canon。

## 1. 数据分层

| 层 | 事实来源 | 是否可删除重建 | 保存方式 |
|---|---|---:|---|
| Canon | 章节、世界观、故事核心、角色、关系、词条、地点、历史、伏笔、参考、物品流水 | 否 | 既有业务表 |
| 检索策略 | 稳定资料 ID、记录/字段启用状态、权重、字段 token 上限 | 否 | 源记录的 `ragDocumentId / ragPolicy` 元数据，随业务表导出 |
| 派生索引 | `retrievalChunks / narrativeSummaryNodes / embedding` | 是 | 现有可重建缓存，不进便携 JSON |
| 过程证据 | 节点精确选择、实际 included/omitted/trimmed、输入/输出 | 否 | `nodeFlows / nodeRuns` |

不新增“RAG 正文表”。资料库每次从现有 Canon 实时投影，避免用户修改角色或章节后还要维护
另一份副本。`ragDocumentId` 不使用 Dexie 自增主键作为跨备份引用；第一次建立投影时为旧记录
补稳定 ID，之后随源记录便携导出。节点图保存 `ragDocumentId + fieldKey`，导入新项目后仍能
解析到同一资料字段。

## 2. 入口与能力

- 工作区“创作区 → 资料与检索库”是独立管理入口。
- 当前覆盖章节正文/摘要/笔记、世界观、故事核心、角色、角色关系、词条动态字段、重要地点、
  历史、伏笔、项目参考和角色物品流水。
- 每条记录显示来源、标题、更新时间、字段数、token 估算、章节切块数和向量状态。
- 记录级可启用/停用并设置默认权重、字段 token 上限；字段可单独启用/停用。
- “重建派生索引”重建章节关键词块和章→卷→全书摘要，不调用 AI；embedding 仍由设置中的
  可选向量配置负责。
- “删除派生索引”只清检索块与派生摘要，不删除章节、设定、角色或检索策略。
- “最近实际召回”读取 `nodeRuns` 的冻结证据，不用当前资料重新推算历史运行。

## 3. 节点模式接入

“项目元素”节点有两种明确模式：

1. **精确资料**：浏览记录和字段，保存稳定字段键；执行时按权重排序，依次应用字段上限和
   节点总预算。
2. **注册来源**：兼容既有 `CONTEXT_SOURCES` 粗粒度选择，适合让装配器按任务动态读取。

精确资料并没有绕开三注册表。节点执行把稳定字段键交给
`CONTEXT_SOURCES.ragSelection → assembleContext()`；`ragSelection` 再调用统一资料投影读取
Canon。运行快照保存：

- 节点当时选择的稳定字段键；
- 实际纳入项、token 数和权重；
- 因源记录删除、资料停用或总预算不足而省略的项；
- 因字段 token 上限而裁剪的项；
- 节点最终输出。

只有后续“内容输出”节点经作者确认后才能走 `adopt()` 写回 Canon；资料选择本身没有写回权限。

## 4. 世界与生命周期

- 世界观、历史、章节和词条按当前世界严格过滤；角色按原属世界或跨世界标记过滤。
- 故事核心、关系、伏笔、参考、地点和物品流水按既有项目级语义显示，不猜测新的世界归属。
- 策略元数据位于既有 exportable 源记录，因此项目删除、世界删除、导出/导入和相关 FK 重映射
  继续由原 `PROJECT_TABLES` 条目负责；本次无需新增 Dexie 表或 schema 版本。
- 删除源记录后，节点中的稳定键在下一次执行进入 omitted 证据，不会召回孤儿内容。
- `retrievalChunks / narrativeSummaryNodes` 继续 `exportable:false`，导入后由作者显式重建。

## 5. 验证证据

- `R-RAG1-visible-library`：实时投影、策略不改 Canon、权重排序、字段/总预算裁剪、停用、
  节点快照、稳定键 JSON 往返、派生索引重建/删除不伤正文。
- `R-FLOW2-free-node-mode`：旧注册来源/普通自由路径、输入输出持久化和确认写回保持兼容。
- `check:architecture`：组件不直读写 IndexedDB，AI 读取仍经 `CONTEXT_SOURCES`。
- 完整 `npm run ci` 已通过 231 个测试文件 / 816 项测试、生产构建、架构/依赖/覆盖率/
  bundle 闸门；完整 Chromium E2E 22/22 通过，其中包含可见资料库精确字段路径。
- 真实工作区浏览器从新建项目开始录入世界来源，资料库实时显示 25-token 原文；把默认权重
  改为 2.5 后，节点精确选择并运行，快照显示实际输入 48 tokens、纳入 1、省略 0、裁剪 0，
  输出与最近召回均可见；隔离验证项目随后完整删除。

## 6. 后续边界

本阶段不包含自动语义检索所有非章节资料、自动 embedding 消费、条件/循环/并行节点、脏下游
自动失效、图模板或 Agent 自动生成图。若未来为非章节资料增加向量索引，仍必须保持“向量是
可重建派生物、Canon 是唯一真相、真实召回可见”三条边界。
