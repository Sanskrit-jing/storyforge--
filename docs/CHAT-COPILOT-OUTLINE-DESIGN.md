# AGENT-1 Phase 27.1-d · ChatCopilot 大纲生成闭环

> 状态：已实现并完成完整交付验证（2026-07-26）。本文只覆盖大纲领域，不代表正文、
> 多 Agent 团队或后台 Agent 已完成。

## 1. 用户故事与唯一归属

- **稳定 ID**：`AGENT-1-27.1-d-outline`。
- 作者只和右侧主 Agent 对话；无需选择“大纲分 Agent”。
- 当前世界没有卷时生成卷级大纲；已有卷时，“章纲/章节规划/一般大纲展开”默认选择作者
  明确提到的卷，否则选择当前世界最后一卷。明确“卷纲/分卷/全书大纲”仍生成新增卷。
- 大纲面板继续是正式查看、编辑和排序入口；Agent 不建立第二套大纲表或隐藏工作区。

## 2. 读、生成与写回

```text
用户目标
  → 主 Agent 计划（outline 领域，可依赖本轮世界/角色任务）
  → 现有 17 个大纲 CONTEXT_SOURCES → assembleContext()
  → 现有 outline.volume / outline.chapter 提示与模型路由
  → JSON [{ title, summary }] 候选
  → 作者可见编辑 / 拒绝
  → 依赖确认 + 快照 + 结构/重复 gate
  → adoptGeneratedOutlineItems() → adopt(outlineNodes)
```

- 读取来源与手工大纲生成入口完全一致，包括 Canon 断言、世界观、故事核心、角色驱动方案、
  力量/修炼、词条、角色、创作规则、历史、地点、伏笔、故事线、已有卷纲和已写正文进度。
- 上游世界/角色候选可作为“本轮未采纳证据”进入提示，但不会冒充 Canon。
- 生成只调用现有 `outline.volume` / `outline.chapter` 类别；确认时不再调用模型。
- 新增卷或章节仍只写 `outlineNodes`；章节正文、细纲、伏笔和故事线不会被自动创建。

## 3. 确定性安全边界

- 候选只允许 `title` 和 `summary`，1–100 项；空值、未知字段、超长、候选内重复和当前
  同层重复均阻断。
- 生成前冻结当前世界的大纲树、更新时间、同层标题和下一个 order；确认时再次读取。
- 最终快照检查、重复检查和整批写回位于同一 Dexie 事务；任一项未完整写入则整批回滚。
- 多世界项目必须先选择世界；新增记录盖当前 `worldGroupId`，其它世界不进入快照或提示。
- 主 Agent 计划若声明大纲依赖本轮世界/角色候选，必须先采纳这些上游候选；拒绝或未确认
  时，下游大纲不能写入正式数据。
- 规划清洗只允许用户明确授权的领域；“角色变化/已有世界观”是大纲约束，不会被扩大成
  新建角色或世界观。模型把“两卷”拆成多个 outline 任务时，代码会合并为单个批量任务并
  恢复用户完整原始要求，避免同快照候选互相作废。
- 刷新后内存 `GenerationNode` 可以丢失，但持久化候选、模式、目标卷和基线快照足以走同一
  解析、并发和 adoption 规则恢复确认。

## 4. 当前非范围

- 不修改既有卷/章摘要；本阶段只新增卷或把一个卷展开为新增章节。
- 不从自然语言任意解析复杂目标位置；卷名明确命中，否则使用当前世界最后一卷。
- 不生成正文、不自动采纳、不并行自治、不后台持续运行。
- 大纲依赖的上游候选必须先采纳；不会把未采纳世界/角色静默变成项目事实。
